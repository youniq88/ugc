# 시댄스(Seedance 2.5) 프롬프트 문법

실전에서 검증된 것만 적는다. 5단계 생성 직전에 읽는다.

## 모델 스펙

| 항목 | 값 |
|---|---|
| model | `seedance_2_5` |
| mode | `t2v` (프롬프트만) / `omni_reference` (참조 이미지 있을 때) |
| duration | 4~30초 (정수) |
| aspect_ratio | `9:16` (숏폼 고정) |
| resolution | `480p` / `720p` |
| generate_audio | `true` — 한국어 나레이션이 이 옵션으로 나온다 |
| medias role | `image_references` (참조 이미지), `start_image`, `end_image` |

**크레딧** (720p 기준, 실측)

| 길이 | 크레딧 |
|---|---|
| 17초 | 110.5 |
| 30초 | 195 |

## 프롬프트 구조

```
{총론 문단 — 비율, 길이, 장르, 화질, 조명}

중요 — {금지·필수 지시 1}
중요 — {금지·필수 지시 2}
...

0~2.5초 : {화면 묘사}. 나레이션 "{대사}"

2.5~5초 : {화면 묘사}. 나레이션 "{대사}"
...
```

- 시간 구간을 `0~2.5초 :` 형식으로 나열하면 시댄스가 컷으로 인식한다
- **`중요 —` 로 시작하는 문단을 총론과 장면표 사이에 따로 세우면 금지 지시가 훨씬 잘 먹는다.** 총론 안에 섞어 넣으면 무시되는 경우가 많다

## 검증된 지시문 (그대로 복사해 쓸 것)

**인물 일관성**
```
처음부터 끝까지 완전히 동일한 인물로 유지한다.
```
컷 전환이 있는 영상에서는 필수. 이게 없으면 컷마다 얼굴이 바뀐다.

**화면 내 글자 금지** — 4종을 다 나열해야 효과가 있다
```
중요 — 화면 안에 글자, 자막, 간판, 로고, 숫자를 절대 넣지 않는다.
```
간판이 나오는 컷에는 컷 설명에 `간판에 글자가 없다`를 따로 박는다.

**얼굴 노출 최소화**
```
중요 — 인물이 카메라를 정면으로 응시하는 장면을 넣지 않는다. 얼굴이 나오는 장면은 단 두 번이고, 둘 다 시선이 카메라가 아니라 자기 손을 향한다. 나머지 장면은 손과 손톱, 매장 화면만 나온다.
```
총론 지시만으로는 부족하다. **얼굴이 없어야 하는 컷마다 앞에 `사람 얼굴 없음.`을 박는다.**

**손 붕괴 방지**
```
중요 — 손이 나오는 모든 컷에서 손가락은 정확히 다섯 개로 그린다.
```
컷 설명에도 `손가락 다섯 개`를 개별로 반복한다. 손은 AI 영상 최대 취약 부위다.

**나레이션형 강제 (립싱크 금지)** — 모든 소재에 넣는다
```
중요 — 모든 대사는 화면 밖 나레이션(보이스오버)이다. 등장인물이 입을 움직여 말하는 장면을 넣지 않는다. 인물이 나오는 컷에서도 입은 다물고 있고, 자연스러운 표정과 행동만 한다. 립싱크를 하지 않는다.
```
레퍼런스가 토킹헤드였어도 이 지시를 넣는다. 한국어 립싱크는 실패율이 높고 입이 안 맞으면 즉시 AI 티가 난다.
인물이 말하던 컷은 **행동 컷이나 사물 컷으로 치환**한다.

**말투 — 존댓말 / 반말**
```
중요 — 여성의 한국어 나레이션이 영상 전체에 깔린다. 반드시 존댓말로 말한다. 반말을 쓰지 않는다.
```

**연기 톤 제거 + 속도**
```
중요 — 말 속도가 매우 빠르다. 보통 사람보다 1.3배 빠른 속도로 말한다. 목소리는 밝고 또렷하고 힘이 있다. 리듬감 있게 몰아친다. 느리게 늘어지거나 힘 없이 웅얼거리는 톤을 절대 쓰지 않는다. 성우가 낭독하는 톤, 과장된 연기 톤, 과장된 리액션도 쓰지 않는다. 친한 친구에게 신나서 빠르게 이야기하는 실제 사람의 말투.
```

위 지시문은 **톤을 통제할 뿐 대사 자체를 고쳐주지 않는다.** 대사에 연기체 표현("대박", "완전", "여러분")이 들어 있으면 아무리 톤을 지시해도 연기처럼 들린다. 카피 단계에서 걸러야 한다 — SKILL.md의 「대사는 연기가 아니라 말이다」 참조.

**발음 정확도**
```
중요 — 나레이션 대사는 아래에 따옴표로 적은 문장을 글자 그대로 정확하게 발음한다. 단어를 바꾸거나 비슷한 발음으로 흘리지 않는다.
```

**UGC 질감**
```
스마트폰으로 직접 찍은 화질, 손떨림이 살짝 있는 핸드헬드. 스튜디오 조명 금지, 생활 조명 그대로.
```

**참조 이미지 연결** (omni_reference)
```
첨부한 참조 이미지의 제품 패키지와 동일하게.
```
해당 컷 설명 끝에 붙인다.

## 컷 길이가 발화 속도를 결정한다

**이 파일에서 가장 중요한 항목.**

시댄스는 컷 길이만큼 대사를 늘려 채운다. 컷이 길면 말이 느려지고 힘이 빠진다.

| 컷당 길이 | 결과 |
|---|---|
| 3.3초 (9컷/30초) | 목소리가 늘어지고 힘이 없다 |
| 2.5초 (12컷/30초) | 자연스러운 브이로그 속도 |
| 20초+ (원테이크) | 강의체 토킹헤드에 적합 |

**나레이션에 속도와 에너지가 필요하면 톤 지시문보다 컷 분할이 먼저다.**

## 나레이션 길이 계산

**한국어 발화는 초당 5음절이 기준.**

```
컷 길이(초) × 5 = 그 컷에 넣을 수 있는 최대 음절 수
```

- 5음절/초 : 편안한 속도
- 6음절/초 : 빠르고 리듬감 있음 (숏폼에 적합)
- 7음절/초 이상 : 뭉개지거나 다음 컷으로 넘어간다

대사를 쓸 때마다 음절을 세고 나눠본다. 초과하면 문장을 자르거나 컷을 늘린다. 넣고 싶은 정보가 계산에 안 맞으면 **영상에서 빼고 캡션이나 댓글로 넘긴다.**

## NSFW 필터 회피

반려되면 status가 `nsfw`로 돌아온다. 크레딧은 차감되지 않지만 4분을 버린다.

**반려된 표현 → 치환**

| 반려 유발 | 안전한 대체 |
|---|---|
| 민소매, 슬리브리스 | 반팔 티셔츠, 셔츠 |
| 침대에 누워 | 소파에 기대어 앉아 |
| 침실 | 방 안 |
| 욕실 | 세면대 앞 |
| 초근접 셀카 (인물) | 얼굴 클로즈업 |

총론에 `두 사람 모두 단정한 일상복 차림`을 넣어두면 통과율이 올라간다.
스킨케어·뷰티 소재에서 특히 자주 걸린다.

## 프롬프트 오타 관리

한국어 장문 프롬프트는 오타가 섞인다. **제출 후 반환된 프롬프트를 반드시 다시 읽는다.**

| 오타 위치 | 조치 |
|---|---|
| 따옴표 안 대사 | **즉시 재생성.** 잘못된 발음이 그대로 나온다 |
| 연출 지시문 | 그냥 진행. 사용자에게 알리기만 |

시댄스가 특정 단어를 계속 흘리면(예: "재택" → "재탁") **그 단어를 아예 다른 표현으로 바꾼다** ("집에서 일하는데"). 같은 단어로 재시도하면 또 틀린다.

## 재생성 원칙

- **전체를 갈아엎지 않는다.** 어긋난 컷의 문단만 고쳐 재생성한다
- AI 영상은 뽑기다. 3~5회 재생성이 정상 범위임을 사용자에게 미리 알린다
- 생성은 4~10분 걸린다. `jobs_wait`는 최대 15초라 `sleep 115` 후 재확인을 반복한다

## 결과 검수 체크리스트

생성이 끝나면 사용자에게 이 항목들을 짚어준다.

- 손가락 개수 (손이 나오는 컷 전부)
- 컷 전환 후 인물 얼굴이 유지되는지
- 화면에 글자·간판·숫자가 생기지 않았는지
- 대사 발음이 정확한지, 존댓말/반말이 지시대로인지
- 목소리 톤과 속도. 밝고 담백한지, 연기하는 것처럼 들리지 않는지
- **인물이 입을 움직이고 있지 않은지** (립싱크가 새어 들어오면 재생성)
- 참조 이미지가 있었다면 제품이 동일하게 재현됐는지
